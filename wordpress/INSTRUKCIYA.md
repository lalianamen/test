# Подключение финансирования AutoPay на myautolux.com (WordPress)

Задача: чтобы посетители сайта могли подать заявку на финансирование, и лид
засчитывался AutoLux через партнёрский канал `AUTOPAY_AUTO_LUX_FAST_TRACK_API`.

Партнёрская ссылка (использовать именно её, целиком):

```
https://apply.autopay.com/unified?partnerUniqueId=&ap%5Ba%5D%5BpartnerRecordUniqueIdentifier%5D=&leadChannel=AUTOPAY_AUTO_LUX_FAST_TRACK_API
```

Программировать ничего не нужно — всё делается в админке WordPress.

---

## Шаг 1. Пункт меню «Get Approved»

1. Админка → **Appearance → Menus** (Внешний вид → Меню).
2. Выберите основное меню сайта.
3. Слева блок **Custom Links** (Произвольные ссылки):
   - **URL** — вставьте партнёрскую ссылку выше.
   - **Link Text** — `Get Approved` (или `Apply for Financing`).
4. **Add to Menu**, перетащите на видное место (лучше — последним, как кнопку).
5. Чтобы заявка открывалась в новой вкладке: вверху страницы **Screen Options**
   → включите галочку **Link Target**, затем в пункте меню отметьте
   **Open link in a new tab**.
6. **Save Menu**.

## Шаг 2. Кнопка на страницах (главная, Credit Applications)

Вариант А — редактор Gutenberg: добавьте блок **Custom HTML** и вставьте
содержимое файла `autopay-button.html` из этой папки.

Вариант Б — Elementor/другой конструктор: добавьте виджет **Button**,
в поле ссылки вставьте партнёрский URL, текст — `Get Approved — Apply Now`,
открытие в новой вкладке.

Рекомендуемые места:
- главная — в первом экране рядом с телефоном;
- страница **Credit Applications** — вместо/над текущими формами
  (заявка AutoPay заменяет и personal, и business анкету);
- страница **Lease Specials** — под списком машин.

## Шаг 3. Проверка (2 минуты)

1. Откройте сайт в режиме инкогнито, нажмите кнопку.
2. Должна открыться страница apply.autopay.com; в адресной строке проверьте,
   что присутствует `leadChannel=AUTOPAY_AUTO_LUX_FAST_TRACK_API`.
3. Тестовую заявку до конца отправлять не нужно (будет мягкий запрос кредита
   по реальному SSN) — достаточно убедиться, что форма открылась.
4. Скажите клиенту проверить, что тестовый переход виден в его партнёрском
   кабинете AutoPay (или уточнить у менеджера AutoPay, что канал активен).

## Частые вопросы

**Куда приходят заявки?** В партнёрский кабинет AutoPay клиента. Сайт заявки
не хранит и не обрабатывает — никакой ответственности за персональные данные
на стороне сайта не возникает.

**Что с Rates API (docs.thesavingsgroup.com)?** Это опция «на вырост»:
показывать живые ставки прямо на сайте. Требует секретный токен и
organization code от The Savings Group и небольшой бэкенд (из браузера API
вызывать нельзя — токен утечёт). Пока у клиента только ссылка — этот пункт
не нужен. Готовый шаблон интеграции лежит в `../integrations/rates-api/`.

**Можно ли пометить конкретный лид?** Да: подставьте значение в параметр
`ap[a][partnerRecordUniqueIdentifier]` (в URL он закодирован как
`ap%5Ba%5D%5BpartnerRecordUniqueIdentifier%5D`) — например, номер клиента из
CRM. Для обычной кнопки на сайте оставляйте пустым.
